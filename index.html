BULK STOCK UPDATE

Update from JSON

Paste a JSON array or choose a .json file. Existing products match by id or product name; omitted fields stay unchanged. New products need name, quantity, unit, and expiry date. This adds/updates only—it will not delete other products.

BULK STOCK ENTRY

Add stock list manually

One product per line, separated with |: Name | Quantity | Unit | YYYY-MM-DD expiry | threshold (optional). Existing products can use just Name | Quantity; new products need a unit and expiry date. Blank lines are ignored.
